# To-Do List 界面与交互设计

## 设计目标

让用户打开应用就能看到任务，快速记录、浏览和完成事项。主界面以列表为中心，编辑细节按需出现，窗口缩小时仍可完成所有核心操作。

已采用暖白专注方向，并制作本项目的独立图标与设计变量。成熟待办产品的公开交互资料用于确定信息层级，本应用使用自己的界面资产。

## 参考产品与取舍

### Todoist

官方 Quick Add 从任务名称输入开始，并允许再展开描述字段。参考其“快速记录，再按需补充细节”的组织方式，为本项目设置固定新增入口与独立任务详情。[Todoist Quick Add](https://www.todoist.com/help/todoist/features/use-task-quick-add-in-todoist-va4Lhpzz)

本项目的具体取舍是：列表只呈现主要任务信息，完整描述进入详情；新增和编辑共享表单规则。本轮不引入项目协作、评论或复杂过滤语法。

### 滴答清单和 TickTick

官方功能页将列表视图分为分类清单、任务和详情三列；帮助资料也区分智能清单与普通清单。参考其“清单导航与任务内容分离”的组织方式，左侧只提供全部、未完成、已完成，中央列表显示当前结果。[TickTick 列表视图](https://ticktick.com/features?language=en_us)、[清单说明](https://help.ticktick.com/articles/7055782283059396608)

本项目保留固定工具栏管理搜索和排序，不把日历、习惯或专注功能加入首版导航。后续确有多清单需求时再扩展侧栏。

### Things

官方提供 Quick Entry 和 Quick Find，并通过功能页面呈现任务、备注和导航方式。参考其低干扰录入思路：打开即输入、详情按需展开、键盘路径清晰。[Quick Entry](https://culturedcode.com/things/support/articles/2249437/)、[Things 功能](https://culturedcode.com/things/features/)

本项目的新增快捷键先限定在应用内部；不直接照搬 macOS 全局快捷键或平台专属行为。公开资料用于交互参考，不构成对当前 Windows 客户端每个像素或交互的复刻承诺。

以上是产品模式参考。最终界面使用一套统一的自定义视觉系统，不混用三款软件的颜色、字体或品牌元素。

## 视觉方向

### A 暖白专注 已采用

借鉴原研哉与日常工具设计中的克制留白，使用暖白画布、深色文字和单一深绿主操作。采用中等密度列表，优先突出任务标题和完成动作。适合长时间使用，且中文界面层级容易保持清晰。

特征为细分隔线、轻量侧栏、少量功能性着色、按需详情面板。下文给出该方向的完整设计系统。

### B 清晰秩序

参考 Massimo Vignelli 的网格与信息层级方法，采用更紧凑的列表、对齐的元信息和中性色。适合任务较多、习惯快速扫描的用户。通过行列组织建立秩序，强调可读性和信息密度。

该方向作为早期密度探索参考；当前实现统一使用 A 方向，并通过舒展、标准、紧凑设置调整列表容量。

### C 深色工作台

参考现代工具产品如 Linear 的精细分隔和单色强调方式，以低亮度中性色搭配低饱和强调色。适合经常在深色环境使用桌面工具的用户。

该方向保留为后续主题扩展参考。若增加深色主题，需要重新核验对比度、状态色和全部组件状态。

## 推荐方向的四项定位

- **界面角色**：高频任务操作工作台，主要内容是任务列表与编辑，不使用封面或营销区。
- **观看距离**：桌面屏幕约 50 至 80 厘米，兼顾鼠标和键盘，正文 16 像素起。
- **视觉温度**：安静、清晰、略带温度，主操作有明确重点。
- **容量检查**：初始窗口调整为 1200 × 800，采用 3:2 比例，并根据屏幕工作区缩放。侧栏 196 像素、折叠后 64 像素，详情面板 340 像素；内容宽度至少 1100 时并列，较窄时详情覆盖。

## 设计系统

采用自定义系统，不将参考品牌的视觉规范视为本项目规范。所有颜色、字号和间距通过 CSS 自定义变量集中维护，组件不得散落硬编码。

### 色彩

- 应用画布 `#F5F6F2`，内容表面 `#FFFFFF`。
- 主要文字 `#202821`，次要文字 `#606A61`。
- 分隔线 `#DDE2D9`，悬停表面 `#EDF1EA`。
- 主操作与焦点 `#245C46`，选中背景 `#E6EFE7`。
- 已完成文字 `#667068`，同时使用选中复选框、删除线及状态文案。
- 危险操作 `#A13D35`，浅色危险背景 `#F9EFEC`。
- 优先级旗帜采用高优先级暖红 `#A13D35`、普通深绿 `#245C46`、低优先级灰色 `#667068`，同时保留文字。列表、详情选择器、选项与专注小窗使用相同表达。

按 sRGB 相对亮度公式计算，正文对画布约 13.95:1，次要文字对画布约 5.18:1，已完成文字对白色约 5.14:1，白色对深绿按钮约 7.79:1。以上是指定色值的静态对比度计算，最终仍需验证实际组件的透明度、背景和各种状态。

### 字体与层级

中文与主要界面统一使用 Noto Sans SC，标题字重 500，正文 400；安装包中随附经过许可核验的本地字体文件，不依赖在线字体。Segoe UI 与 Microsoft YaHei 作为文件加载失败时的回退。

- 页面标题 28 像素，行高 36。
- 详情栏标题 13 像素，以字重和分区建立层级；对话框使用更大的标题。
- 任务标题和主要输入 16 像素，行高 24。
- 描述摘要与辅助文字 12 至 13 像素，行高约 22。
- 时间、数量等次级信息 10 至 11 像素，保持足够行高与对比度。

工具界面采用适合持续阅读的标题比例；不使用营销页的大字标题。正文自然换行，长标题不挤压复选框和操作菜单。

### 间距与尺寸

基础单位 4 像素，使用 4、8、12、16、24、32、48。主内容区内边距 32；窄窗口降为 24。控件高度 40；可点击区域至少 40 × 40，触摸场景增至 44 × 44。

侧栏宽 196，手动折叠后 64；详情并列时宽 340，覆盖模式通常宽 360。任务行高度由内容和密度设置决定，紧凑模式收起描述摘要，任务间用细分隔线组织。列表宽度随窗口变化，不把每个任务包成浮起卡片。

### 圆角与层级

按钮与输入框圆角 8，浮层与对话框圆角 12，复选框圆角 5。页面和任务行主要使用直线分区。普通界面无阴影；菜单与浮动覆盖面板允许一层轻阴影，建议 0 8px 24px 的黑色 10% 透明度，配合分隔线明确边界。

### 动效

悬停与按压 120 毫秒；状态淡入淡出 160 毫秒；详情面板 180 毫秒。统一使用 cubic-bezier(0.2, 0, 0, 1)，不使用弹跳与夸张缩放。开启减少动态效果时取消位移，仅保留必要状态变化。

任务完成后仅在写入成功时确认勾选与淡出。操作中保持任务位置，防止光标下方目标突然变化。

### 图标与文案

线性界面图标统一使用本地打包的 @lucide/vue，应用标识由独立 SVG 生成 PNG 和多尺寸 ICO。窗口、系统托盘和安装程序使用同一应用标识，不显示 Electron 默认图标。

按钮使用明确动词：“新增任务”“创建任务”“保存修改”“删除任务”“撤销”。不向用户展示 IPC、事务、SQL 或模块名。错误提示说明当前结果和可执行的下一步。

## 页面结构

正式应用使用无系统边框窗口及自定义标题栏。顶部显示独立应用图标、小窗入口和自行绘制的最小化、最大化或还原、关闭按钮；拖动区域与按钮点击区域分开。安装包、程序与任务栏均使用本项目图标。

主窗口的关闭按钮直接隐藏工作台到系统托盘，保留当前表单与草稿，不弹出放弃确认。真正退出从系统托盘菜单发起，再处理草稿和已接收操作；小窗关闭只销毁小窗。

```text
┌────────────────────────────────────────────────────────────┐
│ 自定义标题栏                         小窗入口  窗口操作    │
├─────────────┬──────────────────────────┬───────────────────┤
│ To-Do List  │ 全部任务        新增任务 │ 任务详情  关闭    │
│             │ 当前任务数量             │                   │
│ 全部任务    │ 搜索任务        排序     │ 标题              │
│ 未完成      ├──────────────────────────┤ 描述              │
│ 已完成      │ 复选框 任务标题    菜单  │ 优先级            │
│             │        描述摘要          │                   │
│             │        状态与创建时间    │ 创建与更新时间    │
│             │                          │                   │
│             │ 任务列表独立滚动         │ 保存修改  取消    │
└─────────────┴──────────────────────────┴───────────────────┘
```

该图为结构线框，右侧仅在新增或选择任务时打开。未选择时主列表占用剩余空间；不长期保留空白详情列。任务行使用真实数据，原型中的演示内容明确标为演示任务。

### 侧栏

固定三种状态导航及全局数量，选中项使用浅绿背景和文字强调。导航顺序不随数据变化。侧栏底部信息区上方提供展开与折叠开关，折叠后保留图标和悬停提示，状态持久化。无项目或标签功能时不展示预留的空分组。

### 列表头部

显示当前视图名称、当前匹配数量和主按钮。搜索与排序放在紧邻列表的工具栏；不重复设置第二套状态 tabs。手动排序提示只在相关状态出现。

### 任务行

从左到右为完成控件、标题与描述区域、必要元信息及操作菜单。复选框只负责状态，不触发行选中；菜单点击不打开详情。鼠标悬停时显示附加操作，键盘聚焦时同样可见。

标题最多两行，描述摘要一行；完整文本始终可在详情查看。状态和优先级有文字表达，颜色只作辅助。长无空格文本允许断行。

### 新增与详情

共用同一套表单组件、校验规则和错误呈现。新增时标题优先，描述可选，优先级默认普通；编辑时增加只读时间信息。面板底部固定保存与取消区域，中间内容独立滚动。

无改动时保存不可用；保存中展示文字反馈并避免重复提交；失败时保留输入并在相关位置展示错误。草稿保护流程见产品需求，不能通过点遮罩意外丢失编辑。

## 窗口适配

- 推荐初始大小 1200 × 800，常规最小窗口 900 × 600，低分辨率工作区适当缩放。
- 内容视口宽度至少 1100 时，侧栏、列表、详情并列。
- 宽度不足 1100 时，详情以右侧覆盖面板显示；主列表保持可读。
- 有效宽度低于 900 时，侧栏自动压缩但不覆盖手动偏好；核心按钮不能消失。
- 高度不足时列表和表单独立滚动，提交按钮可见，不使用整页横向滚动。

以 CSS 实际视口宽度判断布局，不能只依赖 Electron 窗口物理尺寸。验证 Windows 100%、125%、150% 显示缩放和应用内放大。

## 状态与反馈

每个交互组件覆盖默认、悬停、焦点、按压、禁用和提交中状态。页面另外覆盖首次加载、正常列表、首次空列表、筛选空列表、搜索无结果、读取错误、保存错误和冲突。

普通成功反馈显示约 3 秒，不阻断连续操作；删除撤销按业务约定保留至 8 秒期限。错误不自动消失到无法阅读，提供重试或关闭入口。

文本框、文本域和下拉框聚焦时使用单层深绿色边框，不叠加外侧 outline，避免双边框。搜索框及组合下拉控件由容器统一表示焦点，内部输入不再绘制第二层边框。按钮和导航仍保留 2 像素深绿焦点环及间隔，确保键盘操作可辨识。错误同时显示文案和状态标识；不会仅通过红色表达错误。成功提示通过礼貌的可访问通知播报，紧急失败通过适当的警告语义表达。

## 键盘和可访问性

- Ctrl+N 新增，Ctrl+F 聚焦搜索，Ctrl+Enter 提交当前表单。
- Esc 关闭菜单或面板；存在草稿时进入保护流程。
- Tab 按视觉顺序移动，Space 操作完成复选框，Enter 打开任务。
- 手动排序可通过菜单中的“上移”“下移”完成，边界项禁用对应动作。
- 模态覆盖层限制焦点范围；关闭后回到触发控件。并列详情不是模态，不强制锁定焦点。
- 表单 label、错误说明、复选框和仅图标按钮具有可访问名称。

不将删除绑定到无修饰键的全局 Delete，避免输入或列表焦点不清时误操作。

## 专注小窗

主窗口提供“小窗模式”入口，打开默认 360 × 480 的独立窗口，初次出现在当前屏幕工作区右下角。小窗采用自定义可拖动标题区，可调整尺寸并切换置顶；位置、尺寸与置顶状态单独保存。

小窗呈现未完成任务、优先级旗帜及完成按钮，与工作台使用同一 SQLite 数据源并实时同步。底部提供“打开主窗口”。两个窗口没有父子依赖，关闭或最小化任一窗口不关闭另一个。工作台关闭后直接隐藏至托盘，草稿留在当前会话中；托盘“退出应用”处理草稿后等待已提交操作完成，再关闭所有窗口。

系统托盘图标使用本项目图标，Windows 通知区域的右键菜单提供打开工作台、打开小窗、新建任务、小窗置顶、关闭小窗、立即备份和退出应用。快捷项不创建为任务栏 JumpList。

## v0 原型范围

早期 HTML 原型保留在 design 目录，用于回顾布局与交互取舍。正式应用位于 src，使用真实 SQLite；全新正式数据库按初始化规则写入两条可编辑、可删除的引导任务，一条已完成、一条未完成。原型设计工具栏只用于设计稿。

在单个原型的 Tweaks 面板提供三种密度变体：舒展、标准、紧凑，并允许切换详情展开状态。变体用于选择可读性与容量，不会增加三套生产组件。Tweaks 在关闭后完全隐藏，不进入最终产品功能。

原型只作设计回顾；后续视觉调整同时更新正式 Vue 组件、设计变量和本文档中的行为约定。
