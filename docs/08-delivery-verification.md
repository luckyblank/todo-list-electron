# 1.0.0 交付验证记录

验证日期：2026-10-27。目标平台：Windows x64。本文记录本次实际执行的检查，完整产品验收基线见 [测试与验收](04-testing-and-acceptance.md)。基线中的设计目标不自动视为已通过。

## 交付行为

- Electron + Vue 3 + TypeScript + Pinia，SQLite 由主进程统一读写；渲染进程通过受限 preload 调用具名 IPC。
- 任务新增、编辑、完成、恢复未完成、删除及限时撤销；状态筛选、搜索、创建时间/优先级/手动排序。
- 手动排序使用真实拖拽事件及事务落库。只有全部任务、空搜索、手动排序且无未保存草稿时启用；提供菜单上移和下移作为替代操作。
- 工作台使用自定义标题栏、窗口按钮和应用图标。主窗初始 1200 × 800，按工作区适配并保存后续位置和尺寸。
- 自定义下拉、单层表单焦点边框、底部侧栏折叠按钮，以及暖红/深绿/灰色优先级旗帜。
- 工作台和专注小窗独立。工作台关闭后隐藏到托盘，当前会话中的草稿继续保留；小窗可以独立打开、关闭、拖动、调整尺寸和切换置顶。
- 系统托盘右键提供打开工作台、打开小窗、新建任务、小窗置顶、关闭小窗、立即备份、退出应用。真正退出才处理草稿并等待任务与备份完成。
- 交付 Windows x64 NSIS 安装程序，安装向导允许选择安装目录。
- 安装版首次创建数据库时，原子写入两条可编辑、可删除的引导任务：一条已完成、一条未完成。已有数据库、备份恢复和删空后重启均不补写引导任务。

## 静态检查与数据库测试

本轮执行 `npm run build`，TypeScript、Vue 类型检查及生产构建通过；执行 `npm test`，4 个测试文件、33 项测试全部通过。新增的三项初始化测试验证首次两条引导任务、编辑和删空后的重启、已有空库不补种、空备份恢复及已初始化数据库缺失时不误建空库。`npm run lint` 通过。

数据库与存储测试覆盖任务校验、幂等创建、修订冲突、排序、撤销和过期清理、备份恢复、损坏/缺失数据保护，以及数据目录 junction 路径保护。排序和选择器测试覆盖筛选、关键词及稳定排序；窗口与 IPC 测试覆盖工作区位置约束和可信来源判断。

测试由 Electron 自带 Node 运行，加载正式使用的 better-sqlite3 Node-API 模块。本项目没有用内存仓储替代 SQLite 来获得通过结果。

## 真实 Electron 集成验收

验收入口为 `npm run test:electron`：先构建正式源码，再启动独立 Electron 进程。测试数据使用 `.test-data` 内的 UUID 子目录，不读取或覆盖使用者的正式数据库；测试创建的窗口保持隐藏，不发送桌面鼠标或键盘输入。

脚本通过正式 preload、IPC、Vue DOM 事件和 SQLite 进行验证。托盘菜单调用实际应用生成的菜单回调；该方式验证业务接线，不等同于系统通知区域的人工右键测试。测试关闭自己的托盘气泡反馈，避免干扰桌面。

原始报告写入 `.test-data/electron-smoke-result.json`。界面截图由实际渲染器捕获，使用明确标记的验收示例任务；这些截图任务与安装版的两条引导任务分开，验收数据不会写入使用者的数据库。

本次实际结果：**13 / 13 通过**。Electron 45.0.0、Node 24.22.0、Chromium 156.0.8078.48，整轮集成脚本耗时 10.676 秒；该时间是测试脚本总时长，不是冷启动或 CRUD 性能数据。未记录到渲染器警告或错误。观察到正常 `will-quit` 和 `quit` 事件，退出码为 0。

实际覆盖：

- 正式 preload 与真实 SQLite 新增、编辑、完成，以及 Vue 表单提交。
- Vue `DragEvent` 拖拽，经 IPC 将完整手动顺序提交到数据库。
- 自定义 combobox 打开、键盘选择；页面不存在原生 `select`。
- 输入焦点无外围 outline、边框单层；列表、编辑器及下拉选项复用三色旗帜。
- 小窗没有父窗口、原生 always-on-top 可切换，小窗完成任务同步到工作台 DOM 和数据库。
- 工作台隐藏后草稿仍在、任务服务仍可用，小窗独立关闭和重新打开。
- 托盘实际菜单回调能打开工作台和小窗、新建任务、切换置顶、关闭小窗和创建备份。
- 托盘退出及公开 `app.quit()` 路径完成关闭握手，全部测试窗口正常销毁。

界面证据：[工作台截图](screenshots/workspace.png)、[专注小窗截图](screenshots/mini-window.png)。截图来自真实 Vue 页面；保存前核对编辑器为已保存状态、拖动手柄存在且无临时 toast。原始集成验收 JSON 是本机生成产物，写入 `.test-data/electron-smoke-result.json`，本地归档位于 `docs/verification`，不提交到源码仓库；重新执行验收脚本可生成本次运行报告。
