# To-Do List 用户使用指南

本手册介绍 Windows x64 安装版的任务管理、窗口操作、专注小窗和本地备份。任务保存在当前电脑上，新增、修改和完成操作在保存成功后立即写入本机数据库。

## 安装与启动

使用发布目录中的 `Todo-List-版本号-x64-Setup.exe` 安装包，按安装向导选择位置并完成安装，再从桌面快捷方式或开始菜单启动 To-Do List。正式交付采用 NSIS 安装包；构建过程中的解包目录只用于开发验证。

全新安装且首次创建任务数据库时，正式应用提供两条引导任务：一条未完成、一条已完成。你可以直接编辑或删除它们，也可以点击“新增任务”记录自己的事项。已有数据、应用升级或删除全部任务后不会重新添加引导记录。重复启动应用会唤回已有主窗口。

主窗口在可用工作区足够时以 1200 × 800 的初始尺寸打开，宽高比为 3:2；较小屏幕会适当缩小并居中。调整后的窗口位置、大小和最大化状态会保存，下次启动时恢复；显示器变化时会将窗口限制在可用工作区内。

## 窗口与侧栏

应用使用独立的图标和自定义顶部栏。拖动顶部空白区域可移动窗口，右上角按钮分别用于最小化、最大化或还原、关闭主窗口。点击关闭会直接将工作台隐藏到系统托盘，不弹出放弃修改确认；当前表单和草稿保留，应用继续运行，已打开的小窗不受影响。按钮区域可正常点击，不属于拖动区域。

左侧提供“全部任务”“未完成”“已完成”三个入口。数量表示所有正常任务的状态统计，不随关键词搜索改变。列表头部单独显示当前条件下的任务数量。

侧栏底部的收起按钮可缩小导航区域；收起后可以通过相同位置的展开按钮恢复。手动折叠偏好会保存。窗口较窄时侧栏自动收起，此时先扩大窗口，再手动切换展开状态。

侧栏底部还提供“数据备份”和“显示设置”。显示设置可以切换舒展、标准、紧凑三种密度；紧凑模式收起任务描述摘要，使一屏能浏览更多任务。完整描述仍可在详情中查看。

## 系统托盘

在 Windows 时钟附近的通知区域找到 To-Do List 图标；如果图标被系统折叠，可先展开隐藏图标区域。单击或双击图标可唤回工作台，右键图标打开以下菜单：

- **打开工作台**：显示主窗口并切换到前台。
- **打开小窗**：打开或唤回专注清单小窗。
- **新建任务**：打开工作台并进入新增任务表单。
- **小窗置顶**：小窗已经打开时可切换置顶状态。
- **关闭小窗**：仅关闭小窗，工作台和后台存储继续保留。
- **立即备份**：创建本机任务备份，执行期间菜单显示“备份中…”并防止重复触发；备份结果也可在工作台的数据备份列表查看。
- **退出应用**：处理未保存内容后，结束主窗口、小窗与后台运行。

隐藏工作台不等于退出应用，未提交的表单仍保留在当前会话中，唤回后可以继续编辑。需要彻底退出时使用托盘菜单的“退出应用”；选择取消退出后，两个窗口与任务存储继续可用。

## 新增任务

1. 点击“新增任务”或列表底部的新增入口，也可以按 Ctrl+N。
2. 输入任务标题，按需要填写描述并选择优先级。
3. 点击“创建任务”或按 Ctrl+Enter。
4. 出现创建成功反馈后，任务进入已保存的未完成列表。

标题必填，去除首尾空白后最多 120 个 Unicode 字符，不能包含换行或控制字符。描述可不填，最多 2,000 个 Unicode 字符，允许多行。标题允许重名，每条任务按独立标识管理。

任务文本按纯文本显示。描述中的 HTML、链接文本或格式标记不会作为脚本执行，也不会自动变成富文本。

新增默认未完成、普通优先级。如果当前在“已完成”视图或输入了不匹配的关键词，新任务可能不会显示在当前列表中；成功提示中的“查看任务”可切换条件并定位该任务。

## 查看与编辑

点击任务标题打开右侧详情，修改标题、描述或优先级后点击“保存修改”。窗口较宽时列表与详情并排显示；窗口较窄时详情显示为覆盖面板。

表单输入与已保存任务分开处理。只有保存成功后，列表才确认使用新内容；保存失败时会保留输入，并显示可以继续处理的错误提示。没有实际修改时，保存按钮不可用。

关闭详情、切换到另一条任务或从托盘退出应用时，如果有未保存修改，会出现以下选择：

- **保存并继续**：保存成功后执行原操作；保存失败则继续保留表单。
- **放弃修改**：保留上一次已保存内容，继续原操作。
- **取消**：留在当前表单中。

搜索与状态筛选不会直接丢弃打开的草稿。如果任务不属于新的筛选结果，详情中会说明它当前不在结果列表内。

## 完成与恢复未完成

点击任务左侧复选框标记完成，再次点击可恢复未完成。完成任务使用勾选、删除线和状态文字共同区分。

在“未完成”视图中完成任务后，该项会从当前结果中移出；在“已完成”视图中恢复未完成也同理。这表示状态变化，不是任务丢失。切换到“全部任务”可以查看。

状态变化不修改创建时间或手动顺序。如果当前任务有未保存编辑，应用会先处理草稿，再执行完成、删除等操作。

## 删除与撤销

打开任务右侧的更多操作菜单，选择“删除任务”；详情面板中也提供删除入口。删除成功后，任务不再进入正常列表、搜索结果或状态数量。

删除反馈提供 8 秒撤销入口。点击“撤销”恢复原任务的内容、完成状态和创建时间。撤销期限从删除成功时开始计算，不会因悬停、刷新或重启重新计时。

期限内恢复成功后，如果任务仍被当前条件隐藏，可通过“查看任务”定位。过期后不提供回收站；需要回到更早数据时，可以选择相应备份恢复整个任务集合。

## 搜索与排序

在列表顶部搜索任务标题或描述。英文大小写与全半角差异按统一检索规则处理，输入短暂停顿后更新结果。搜索使用关键词包含匹配，不需要正则表达式或特殊搜索语法。

搜索与左侧状态筛选共同生效。点击清除搜索只移除关键词，保留当前状态筛选和排序方式。

排序入口提供四种模式：

- **最新创建**：新创建的任务在前。
- **最早创建**：较早创建的任务在前。
- **优先级从高到低**：高、普通、低；同优先级按创建时间排列。
- **手动排序**：使用拖动或菜单调整后的顺序。

排序、优先级和显示设置均使用自定义选择菜单。鼠标点击展开后选择，也可以用方向键移动、Enter 确认、Esc 收起。

优先级以旗帜和文字表示：高优先级为暖红色，普通为绿色，低优先级为灰色。颜色只作辅助，任务仍有明确等级文字。

## 拖动调整顺序

手动调整需要同时满足以下条件：当前为“全部任务”、搜索为空、排序选择“手动”，且没有未保存的编辑内容或正在提交的操作。

任务左侧出现拖动手柄后，拖动到目标位置，观察插入提示并松开。顺序保存成功后确认更新。也可以在任务菜单中使用“上移”“下移”，无需鼠标拖动。

切换到自动排序不会覆盖原有手动顺序。再次选择手动排序后，可以继续使用之前保存的排列。

## 专注小窗

点击主窗口顶部的“小窗模式”打开独立的专注清单。首次打开时，小窗以约 360 × 480 的尺寸出现在主窗口所在显示器的工作区右下角，适合在处理其他工作时查看待办。小窗显示未完成任务，排序沿用主窗口设置。

小窗支持以下操作：

- 拖动自定义顶部栏改变位置，并调整到适合的尺寸。
- 使用置顶按钮决定是否保持在其他普通窗口上方；置顶偏好会保存。
- 勾选任务完成，结果同步到主窗口；主窗口中的任务变化也同步到小窗。
- 使用底部的“打开主窗口”入口唤回主窗口，继续新增任务或编辑描述。
- 关闭小窗时只收起该窗口；隐藏主窗口不会关闭小窗；选择托盘菜单“退出应用”时，小窗一并关闭。

小窗与主窗口使用同一份任务数据库。它不是另一份任务副本，不需要在两个窗口之间手动保存或导入。

## 备份与恢复

### 创建备份

打开侧栏底部的“数据备份”，点击“创建备份”。列表显示备份时间、类型和大小。备份保存在本机应用数据目录中。

应用首次建立有效数据库时创建基线备份，之后按每日检查生成自动备份。日常自动备份保留最近 7 份，迁移或恢复前的保护备份保留最近 3 份；手动备份不参与日常自动轮换。

自动备份失败时，已经成功保存的任务仍保留，应用会提示检查可用空间并重试备份。本机备份与原数据位于同一设备，设备整体故障需要另有外部备份才能恢复。

### 恢复备份

1. 在备份列表中选择目标时间，点击“恢复”。
2. 阅读确认信息：当前任务将替换为该备份时刻的内容。
3. 确认恢复并等待完成。
4. 恢复后重新查看任务，搜索与旧编辑状态会清理。

正常数据库恢复前会先保存保护备份。如果原数据库已损坏，应用会先验证所选备份，再将原文件隔离保留，避免用空数据覆盖它。

恢复是整个任务集合回到备份时刻，备份之后新增、修改或删除的结果不会继续出现在恢复后的集合中。选择备份前应核对时间；恢复后也可能再次看到该时间点尚未删除的任务。

### 无法读取任务时

如果启动显示无法读取任务，先使用“重新读取”。仍不可用时，从错误页面或侧栏进入备份恢复。应用识别到已使用的数据目录中数据库缺失，或者上次恢复未完成时，会保留错误状态，不会自动新建空库。

不要删除初始化或恢复标记来跳过该保护。需要排查时，先保留整个数据目录及原始文件，再根据错误提示处理。

## 数据位置与退出

Windows 安装版默认数据目录为 `%APPDATA%\To-Do List`。主要内容包括：

- `data\tasks.sqlite`：任务与显示偏好。
- `backups`：可用备份。
- `recovery`：恢复暂存文件和隔离的原始数据库。
- `window-state.json`：主窗口位置、大小与最大化状态。
- `mini-window-state.json`：小窗位置、大小与置顶偏好。
- `.initialized.json` 与 `.recovery-pending.json`：初始化和恢复保护标记。
- `application.log`：本地诊断记录。

已成功提交的任务会即时保存，任务数据不存放在浏览器 LocalStorage 中。主窗口关闭仅隐藏到托盘；从托盘选择“退出应用”时，才处理草稿，并等待提交与备份操作结束后退出。强制结束进程不能保留尚未提交的表单内容。

卸载程序默认保留用户数据，便于重新安装后继续使用。清理应用数据是独立操作，不等同于卸载安装文件。

## 常用快捷键

- Ctrl+N：新增任务。
- Ctrl+F：聚焦搜索。
- Ctrl+Enter：保存当前任务表单。
- Esc：收起当前菜单或详情；有修改时先处理草稿。
- Tab：在控件之间移动。
- Space：操作获得焦点的完成复选框。
- 方向键、Enter、Esc：操作自定义选择菜单和任务操作菜单。

中文输入法确认候选词期间不会将组合输入误作快捷提交。输入框聚焦时只显示单层深绿色边框。

## 当前交付边界

当前以 Windows x64 安装包为交付目标，使用本机离线数据，不包含账号、云同步或多人协作。公开分发所需的代码签名证书尚未配置，正式公开发布前需要补充签名与分发渠道验证。
