# To-Do List 测试与验收方案

## 验收原则

按可观察行为验收，覆盖界面、进程通信与真实持久化。自动化优先验证纯规则、事务和失败恢复；焦点、输入法、显示缩放和安装包通过专项人工检查补充。

本文是功能与可靠性的验收基线。实际执行结果、构建信息和验证边界记录在交付验证报告中，不将验收计划等同于已完成测试。

## 测试层次

### 单元测试

验证标题和描述规范化、Unicode 计数、状态筛选、关键词包含匹配、稳定排序、草稿状态和错误映射。测试以输入与预期结果为依据，避免仅重复实现过程。

### 集成测试

使用真实 SQLite 临时数据库验证任务 CRUD、唯一新增请求、修订号、重排事务、删除撤销、迁移、备份和损坏恢复。针对磁盘或权限错误使用受控故障注入，不改动真实用户目录。

IPC 校验覆盖未知来源、子 frame、越界字段和无效枚举；事务失败后检查旧数据和集合版本都未改变。

### 组件与端到端测试

组件验证字段错误、保存状态、草稿保护和焦点回归。Electron 端到端测试连接真实 main、preload 与 renderer，使用独立 userData 目录完成创建、编辑、完成、删除、重启留存和恢复流程。

真实安装包另做冒烟，验证原生 SQLite 模块可加载，而不是只对开发启动进行测试。

## 核心验收案例

- **AC-01 新增合法任务 对应 FR-01**：输入中文标题和多行描述，成功后列表、详情、计数一致；重启后内容仍在。
- **AC-02 输入边界 对应 FR-01 FR-08**：空串和纯空白不能提交；标题 120 个码点可提交，121 个不允许；描述 2,000 与 2,001 的边界正确；组合 emoji 使用既定码点口径。
- **AC-03 重复提交 对应 FR-01**：快速连点只创建一条；丢失首次响应后用同一 createRequestId 重试，任务 ID 与数量不变。
- **AC-04 编辑保存 对应 FR-02**：修改标题和描述后保存，创建时间不变，更新时间与修订号变化，重启后保留。
- **AC-05 取消编辑 对应 FR-02**：修改后选择放弃，原任务不变；选择取消保留编辑；选择保存并继续仅在成功后离开。
- **AC-06 同名任务 对应 FR-02 FR-03**：创建两个同名任务，独立编辑、完成和删除，不误操作另一条。
- **AC-07 完成切换 对应 FR-04**：状态、完成时间和数量同步；恢复未完成后完成时间清空；不改变创建时间和手动顺序。
- **AC-08 三种筛选 对应 FR-05 FR-06**：全部为未完成与已完成之和；筛选下切换状态正确移出结果，反馈可理解。
- **AC-09 持久化 对应 FR-07**：新增、编辑、状态切换、删除、撤销分别成功后重启，任务状态一致。
- **AC-10 删除与撤销 对应 FR-03**：删除后立即不计入列表，8 秒内恢复原 ID、内容、状态和创建时间；撤销失败不显示虚假恢复。
- **AC-11 撤销期限 对应 FR-03**：主进程控制期限；悬停、刷新和重启不重置；超期返回明确错误。多次删除各自撤销，不恢复其他任务。
- **AC-12 引导初始化与空列表 对应 FR-05 FR-08 FR-20**：全新正式数据库首次打开有两条可编辑、可删除的引导任务，一条已完成、一条未完成；开发及仓储测试默认空库。已有用户、升级、删除全部任务后重启均不补种；正常集合为空时显示新增入口，筛选空与搜索空提示不同。
- **AC-13 新增不可见 对应 FR-01 FR-06**：在已完成筛选或不匹配关键词下新增，任务仍成功保存；“查看任务”可切换条件并定位新任务。
- **AC-14 列表与事件 对应 FR-04 FR-05**：复选框不打开详情，菜单不触发行选择；长标题和描述不覆盖控件。

## 增强验收案例

- **AC-15 搜索 对应 FR-09**：标题和描述均可命中；忽略英文大小写并归一化全半角副本；不改用户原文，不执行正则。
- **AC-16 组合筛选 对应 FR-06 FR-09**：状态与关键词共同生效；清空关键词不改变筛选；侧栏全局计数不随关键词改变。
- **AC-17 稳定排序 对应 FR-10 FR-11**：最新、最早、优先级顺序正确；时间相同或优先级相同以约定条件稳定排序；多次重读结果一致。
- **AC-18 手动顺序 对应 FR-12**：全局正常任务重排后重启保持；切换自动排序再切回，原手动顺序保留。
- **AC-19 禁用重排 对应 FR-06 FR-09 FR-12**：存在搜索、状态非全部、排序非手动、未保存草稿或提交中操作时，鼠标与键盘均不接受重排。
- **AC-20 重排失败 对应 FR-12**：提交失败恢复原顺序；遗漏、重复、未知 ID 或集合版本过期被拒绝，不产生部分写入。
- **AC-21 撤销与重排 对应 FR-03 FR-12**：删除期间其他任务重排，再撤销，按保留顺序值和 ID 稳定插入，其他任务相对顺序不变。

## 可靠性与安全验收案例

- **AC-22 读取失败 对应 FR-07 FR-08**：数据库不可读时显示错误与恢复入口，不把异常当空列表，不覆盖原文件。
- **AC-23 写入失败 对应 FR-07 FR-08**：模拟只读目录、磁盘错误或事务失败，不显示成功；已有快照和草稿保留。
- **AC-24 结果未知 对应 FR-07**：模拟提交成功而响应丢失，先重新读取结果，不重复新增或盲目重复操作。
- **AC-25 修订冲突 对应 FR-02**：旧草稿不能覆盖新修订，冲突时保留草稿；刷新内容需明确处理未保存输入。
- **AC-26 真正退出的草稿保护 对应 FR-07 FR-08 FR-19**：从系统托盘或应用 quit 发起退出时，保存、放弃和取消三个分支正确；保存失败保留表单且不退出。主窗口 X 只隐藏，不进入该确认流程；renderer 无响应时提供明确退出回退。
- **AC-27 崩溃恢复 对应 FR-07**：成功提交后强制终止，再次启动任务保留；未提交事务不出现半条记录。该项不等同于所有硬件故障测试。
- **AC-28 数据迁移 对应 FR-07**：旧数据库升级数据完整；迁移中失败回滚；较新 schema 被旧版本拒绝写入；迁移前保护快照可验证。
- **AC-29 备份 对应 FR-07**：一致快照通过 quick_check；备份失败仍保留已提交任务与旧备份；正常轮换不误删迁移保护副本。
- **AC-30 恢复 对应 FR-07**：有效备份可恢复；错误或较新格式被拒绝；健康数据库替换失败回滚；损坏数据库恢复保留原始隔离文件，暂存校验失败不切换。
- **AC-31 IPC 边界**：未知 sender、子 frame、无效参数、任意文件路径及 SQL 不能触发业务操作；renderer 无原始 Node 或 ipcRenderer 能力。
- **AC-32 文本安全**：标题和描述中的 HTML、脚本、路径和协议文本仅按纯文本展示，不执行。
- **AC-33 单实例与升级**：重复启动唤醒原窗口；安装升级后使用相同数据路径；开发和测试不污染正式目录。
- **AC-34 日志**：日志包含错误类别和诊断信息，不包含任务正文、完整 IPC payload 或撤销 token。
- **AC-35 已删除请求去重 对应 FR-01 FR-03**：任务软删除或物理清理后，原 createRequestId 再次提交被拒绝，不使已删除任务复活；主动新增使用新请求 ID。
- **AC-36 恢复中断 对应 FR-07**：分别在备份校验、隔离原文件、切换和重新打开阶段终止应用；重启能识别恢复状态，不误建空库、不丢原始文件。
- **AC-37 恢复隔离 对应 FR-07**：恢复期间不接受新写入；旧队列先排空，成功后按健康或损坏分支设置集合版本并轮换 dataEpoch；版本只在同一 epoch 比较，恢复前迟到请求和响应不能改写新状态。

## 桌面与最终交互验收案例

以下新增案例定义最终桌面行为，需要将执行方式、结果与边界逐项记入交付验证报告。增加案例不表示已经完成新的 Windows 人工验收。

- **AC-38 自定义窗口与图标 对应 FR-13**：主窗和小窗均没有系统原生顶部栏，应用标识及安装程序使用本项目图标；拖动区能移动窗口，按钮不被拖动区截获，最小化、最大化和还原行为正确。
- **AC-39 初始比例与位置恢复 对应 FR-13**：清空测试窗口偏好后，在足够的工作区以 1200 × 800、3:2 比例居中打开；较小工作区适配可用范围。调整位置、大小与最大化后重启能够恢复，移除外接屏幕后窗口仍可见。
- **AC-40 单层聚焦边框 对应 FR-08 FR-13**：标题、描述和搜索输入聚焦时只有一层深绿色边框；组合控件内部不叠加 outline。按钮、复选框和导航仍有可辨识的键盘焦点。
- **AC-41 自定义下拉 对应 FR-14**：排序、优先级、密度使用自定义弹层，显示当前选中项；鼠标、方向键、Enter、Esc 与 Tab 操作一致，点击外部可收起。对话框内的弹层可见且不被裁切，不出现原生 select 外观。
- **AC-42 侧栏折叠 对应 FR-15**：底部开关能展开、收起，折叠后图标和提示可用，重启保留手动偏好。窄窗自动收起不覆盖该偏好，恢复窗口宽度后遵循原选择。
- **AC-43 三色旗帜 对应 FR-11 FR-18**：高优先级暖红、普通深绿、低优先级灰色，列表、详情、下拉选项和小窗一致；同时具有文字或可访问名称，不只依赖颜色识别。
- **AC-44 真实拖拽 对应 FR-12**：在全部任务、空搜索、手动排序且无脏草稿时，用实际拖动手柄产生插入提示，放下后顺序持久化，重启仍一致；上移、下移与拖动使用相同的全局顺序规则。
- **AC-45 两窗独立与隐藏保留 对应 FR-16 FR-19**：两个窗口同时打开时，带未保存草稿点击主窗 X，工作台直接隐藏且不弹出丢弃确认，小窗继续可用；从托盘唤回后草稿完整。小窗 X 只销毁小窗，主窗及存储仍正常；最小化任一窗口不连带操作另一窗口。
- **AC-46 小窗位置与置顶 对应 FR-16**：首次约 360 × 480 位于当前显示器工作区右下方；标题可拖动且显示应用名称，窗口按钮可点击，置顶开关和保存后的状态一致。移动、缩放后再次打开保留有效位置，移除显示器后不会出界。
- **AC-47 双窗任务同步 对应 FR-04 FR-07 FR-16**：小窗完成任务后主窗列表和计数更新，主窗新增、修改或完成任务后小窗更新。主窗隐藏时同步继续；小窗操作不覆盖主窗脏草稿，旧修订保存产生明确冲突。
- **AC-48 系统托盘菜单 对应 FR-19**：Windows 通知区域图标可单击或双击唤回工作台；右键提供打开工作台、打开小窗、新建任务、小窗置顶、关闭小窗、立即备份和退出应用。小窗关闭时相关项目禁用，状态变化后菜单更新；快捷项不注册为任务栏 JumpList。
- **AC-49 托盘异步备份 对应 FR-07 FR-19**：点击立即备份后显示“备份中…”并禁止重复提交，结束后恢复菜单；备份列表与实际结果一致。在系统允许通知时提供简短反馈，反馈不含任务正文、完整路径或撤销 token；失败不破坏任务保存。
- **AC-50 退出取消与命令竞争 对应 FR-08 FR-19**：退出确认中取消后，两个窗口与数据服务继续工作，后续主窗 X 仍只隐藏；确认期间托盘新建不能覆盖当前草稿保护动作。无响应回退中放弃退出后，旧退出标记不影响后续窗口操作。
- **AC-51 退出排空队列 对应 FR-07 FR-19**：已有任务提交或备份时发起真正退出，停止接收新的变更，等待已接收任务与备份结束，再关闭连接、两个窗口与托盘。重复退出不重复提示；退出过程中不能再次创建窗口或提交新任务。
- **AC-52 NSIS 安装交付 对应 FR-13 FR-17**：交付 Windows x64 Setup 安装包，安装向导支持选择目录，安装后应用图标与 SQLite 资源可加载，任务在重启及升级后保留；卸载默认保留用户数据。打包中间目录不作为便携版交付，代码签名状态如实记录。

## 人工体验检查

- 仅用键盘可完成新增、编辑、完成、筛选、删除、撤销与手动上移下移。
- 中文输入法确认候选词不误提交；组合输入期间错误和搜索不跳变。
- 文本输入使用单层聚焦边框，其他控件焦点可见；模态焦点不逃逸，关闭后返回触发控件。
- 核验 1200 × 800 主窗、900 × 600 窄窗、360 × 480 小窗，以及 Windows 100% / 125% / 150% 缩放与应用内放大时的关键控件可达性。
- 极长无空格文本、多行描述、空描述、全部完成和无匹配结果布局正确。
- 正常、悬停、焦点、禁用、保存中和错误状态可区分，完成状态不只依赖颜色。
- 减少动态效果启用后无非必要位移；高对比需求下检查文本和焦点可辨识。
- 控制台无未处理错误；所有警告经核查，不把真实异常隐藏掉。

## 性能目标

以下为拟定验收目标，并非当前已测结果。基准为 Windows 11、SSD、至少 4 个逻辑核心和 8 GB 内存，生产构建，1,000 条任务，描述平均约 200 个字符；测试报告记录实际机器配置。

- 冷启动到可操作目标 2 秒内。
- 搜索输入停止后，包含 150 毫秒去抖的结果更新目标 300 毫秒内。
- 单条正常 CRUD 持久化响应 P95 目标 200 毫秒内。
- 数据库操作不得持续造成主线程超过 50 毫秒的阻塞；超标时先分析查询、事务和 Worker 边界。
- 5,000 条任务压力场景确认无界面冻结、遗漏和顺序错误，性能指标单独记录。

启动测量至少重复 5 次；CRUD 至少采样 100 次并给出分位数。机器和数据条件不一致时不能将结果直接比较。大规模数据与长描述的内存占用单独记录，达到瓶颈后再决定分页或虚拟列表。

## 发布门槛

发布前应完成核心案例、已启用增强功能及最终桌面行为的对应验收。数据丢失、错误覆盖、无法启动和无法保存属于发布阻断问题。

发布验证需包含类型检查、静态检查、业务单元测试、SQLite 集成测试、关键 Electron 流程和真实 Windows 安装包冒烟。测试报告分别标注自动化和人工项目的版本、系统、CPU 架构、结果、数据目录隔离方式、已知问题和复现步骤。

交付物包含使用说明、开发说明、架构与数据迁移说明、备份恢复说明、验收报告和版本变更记录。当前设计文档在实现后同步更新为实际行为。
