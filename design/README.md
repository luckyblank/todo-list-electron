# To-Do List 设计稿使用说明

本目录提供暖白专注方向的 v0 设计稿，用于确认任务列表、详情编辑、操作反馈与信息密度。所有内容为演示数据，任务仅保存在当前页面内存中，刷新恢复初始任务。

## 打开方式

使用浏览器打开 [设计稿 HTML](<To-Do List Design.html>)，保持同目录的 prototype-interactions.js 与 assets 文件夹完整。也可以在项目根目录运行 Python 静态服务：

```powershell
python -m http.server 5174 --bind 127.0.0.1 --directory design
```

随后访问 [本地设计预览](http://127.0.0.1:5174/To-Do%20List%20Design.html)。这只是设计预览服务，不是正式应用的运行方式。

## 可体验的内容

- 查看全部、未完成与已完成任务，切换完成状态。
- 新增、编辑、删除任务，删除后 8 秒内撤销。
- 搜索标题或描述，切换创建时间和优先级排序。
- 手动排序模式下通过任务菜单上移或下移。
- 关闭未保存表单时体验保存、放弃和取消操作。
- 右上角“设计选项”切换舒展、标准、紧凑三种密度，以及空列表、无匹配、读取中和读取错误场景。

窄窗口首次打开时默认收起详情，点击任务再展开；宽窗口可以同时查看侧栏、列表和详情。窗口顶部的系统按钮为外观示意，实际窗口管理由后续 Electron 实现。

## 本轮修订

根据设计评审反馈，文本框、文本域和下拉控件聚焦时只保留单层深绿色边框，取消重复的外部 outline。搜索与组合选择控件由外层容器统一表示聚焦，内部输入不再绘制第二层边框。

## 原型验证

已在浏览器中检查正常列表与详情，走通新增、状态切换、状态筛选、搜索、删除和撤销。JavaScript 语法检查通过，浏览器当前检查未发现控制台警告或错误。该验证仅针对设计原型，不包含正式 SQLite、Electron 安装包或持久化测试。
